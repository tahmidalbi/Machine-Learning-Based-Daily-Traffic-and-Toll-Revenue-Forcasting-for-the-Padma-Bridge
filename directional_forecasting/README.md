# Padma Bridge Directional Forecasting

Independent implementation of `ashique portion work.pdf`. The source project is
read-only: this folder reads the original Padma CSV and writes all models, tables,
figures, and the final PDF below this directory.

Run:

```powershell
python train_directional.py
```

Outputs are written to `outputs/`, trained estimators to `models/`, and the final
submission report to `directional_model_training_results.pdf`.
